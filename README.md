# AIトークン予算 試算ツール

自社の人数と給与を入れると、生成AIの年間利用料・人件費比・ROI・経費計上の下書きを作るツールです。すべての数字に根拠と区分（公式価格・公的統計・入力値・仮置き）を表示します。

- 背景と設計の考え方：（Wantedly ストーリーのURLをここに記入）

## できること

- 職種別の人数と席の種類から、AI利用料（月額・年額）と人件費比を計算する
- 対象業務の時間と削減率から、効果とROIを計算する
- 勘定科目つきの経費計上の下書きと、稟議用のテキストを書き出す
- 経理・情報システム・経営企画・人事の確認項目をつけて、暗号化した共有コードで部署間を回す

## 入力した情報を外に出さない仕組み

このツールは `index.html` 1ファイルで完結し、サーバー側の処理はありません。次の点はコードで確認できます。

| 確認したいこと | コード上の根拠 |
| --- | --- |
| 外部へ通信しない | `<head>` の Content-Security-Policy で `connect-src 'none'`、`form-action 'none'`、`img-src data:` を指定 |
| 通信遮断が効いているか | 起動時に存在しないアドレス（`csp-check.invalid`）への通信を試み、遮断されたことを画面右上に表示する。コード中で唯一の `fetch` はこの確認用 |
| 保存しない | `localStorage`、`sessionStorage`、`IndexedDB`、Cookie を使っていない |
| 共有コードの暗号化 | Web Crypto API の AES-GCM（256ビット）。鍵は合言葉から PBKDF2（SHA-256、31万回）で作成 |

自分で確かめる方法：

1. `index.html` を開き、`fetch`、`XMLHttpRequest`、`sendBeacon`、`WebSocket`、`localStorage` を検索する。
2. ブラウザの開発者ツールの「ネットワーク」タブを開いたまま入力し、通信が発生しないことを見る。

ブラウザ拡張機能はページの内容を読める場合があります。会社で使う場合は [ADMIN_GUIDE.md](ADMIN_GUIDE.md) の設定例を参照してください。

## 社内で使う

`index.html` の冒頭にある `window.AITB_CONFIG` を書き換えると、料金・為替・勘定科目・共有先部署・社内ルールを全社でそろえられます。配布方法と拡張機能の管理は [ADMIN_GUIDE.md](ADMIN_GUIDE.md) にまとめています。

## 注意

- 試算には仮置きの数値（為替、賞与月数、削減率など）を含みます。パイロット導入の実測値で置き換えてください。
- 勘定科目や消費税の扱いは会計方針によって異なります。経理担当・税理士に確認してください。
